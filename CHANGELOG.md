# Changelog

## 1.0.0 - 2026-09-11

- Initial public release.
- Added seven configurable XInput gadget shortcuts.
- Added native gadget selection and firing without opening the gadget wheel.
- Added a repeat window and automatic Web Shooter restoration.
- Added automatic Steam startup through Overstrike and the Script Hook bootstrap.
- Added readable gadget names in `QuickGadgets.ini`.
